# 📊 Customer Behavior Analysis – Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end **data analytics workflow** focused on analyzing customer behavior and purchasing patterns. It covers the complete analytics lifecycle, from raw data ingestion to insight delivery through dashboards, reports, and presentations. The project is designed to reflect real-world analytics practices commonly used in business environments.



## 📂 Dataset

* Source: CSV / Excel file (synthetic or business-style dataset)
* Content includes customer details, purchase history, and transaction-related attributes
* The dataset is used for analysis, segmentation, and visualization purposes only


## 🛠️ Tools & Technologies

* **Python**: Pandas, NumPy, Matplotlib, Seaborn
* **SQL**: PostgreSQL / MySQL / SQL Server
* **Power BI**: Interactive dashboard and KPI visualization
* **Gamma**: Presentation (PPT) creation
* **Jupyter Notebook**: Python analysis environment


## 🔄 Project Steps

1. Loaded the dataset into Python for initial exploration
2. Performed **Exploratory Data Analysis (EDA)** to understand patterns and trends
3. Cleaned and preprocessed data (handling missing values, formatting, filtering)
4. Wrote SQL queries for data aggregation, joins, and customer segmentation
5. Imported processed data into Power BI
6. Built an interactive dashboard with KPIs and visual insights
7. Created a summary report and presentation using Gamma


## 📊 Dashboard

The Power BI dashboard includes:

* Customer segmentation (New vs Returning customers)
* Purchase frequency analysis
* Key performance indicators (KPIs)
* Interactive filters and visuals for business analysis


## 📈 Results & Insights

* Identified customer purchase behavior trends
* Highlighted repeat and high-value customers
* Provided insights to support data-driven decision-making
* Delivered clear visual storytelling for stakeholders



## ▶️ How to Run the Project

1. Clone the repository

   git clone <repository-url>
   
2. Open the Python notebooks and install required libraries

   pip install pandas numpy matplotlib seaborn
   
3. Run SQL scripts on PostgreSQL / MySQL / SQL Server
4. Open the Power BI `.pbix` file to view the dashboard
5. Review the report and presentation files for summarized insights
